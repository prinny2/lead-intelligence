# Lead Intelligence

A Python toolkit for lead analysis and scoring.

## Project Structure

```
lead_intelligence/     # Main package
  __init__.py
  analyzer.py          # Lead analysis logic
  scorer.py            # Lead scoring utilities
tests/                 # Test suite
  __init__.py
  test_analyzer.py
  test_scorer.py
```

## Getting Started

### Prerequisites

- Python 3.10+

### Installation

```bash
python -m venv .venv
source .venv/bin/activate
pip install -r requirements.txt
```

### Running Tests

```bash
pytest
```
